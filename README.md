# JobHub – Full Stack Job Portal

## Project Overview

JobHub is a Full Stack Web Application developed using Django and MySQL. The application provides a platform for administrators to manage job postings and for candidates to search and apply for jobs.

The system supports bulk job import through CSV upload and Excel copy-paste, ensuring efficient data management. Secure authentication is implemented so that only authorized administrators can import, edit, or delete job data, while candidates can browse jobs and submit applications.
